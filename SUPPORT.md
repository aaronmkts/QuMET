# Support

## Ask for Help

For usage questions, configuration help, or general discussion about QuMET workflows, open a GitHub issue at [GitHub Issues](https://github.com/aaronmkts/QuMET/issues) and mark the title with `question:` or `discussion:` so maintainers can triage it quickly.

## Report Bugs

For defects or regressions, open a GitHub issue with:

- the failing command, script, or import path,
- the dataset/model/config involved,
- the full error output,
- enough context to reproduce the problem locally.

## Request Features

For new models, datasets, CLI options, or documentation improvements, open a GitHub issue describing:

- the workflow gap,
- the proposed behavior,
- whether the request is a feature addition or a change to existing behavior,
- any compatibility or reproducibility constraints that matter.

Small, concrete requests are easier to review and schedule than broad roadmaps.
