# Research-memory boundary

QuMET is the PhD testing-platform/software-quality stream. The repository should document the software platform itself: installation, CLI/API usage, tests, packaging, configuration, examples, and JOSS-facing reproducibility material.

Canonical research note:

- Obsidian: `Research/PhD/QuMET.md`

Repository docs should contain:

- installation and environment setup
- package/CLI/API usage
- test-running instructions
- configuration documentation
- reproducible example workflows
- JOSS software documentation

Repository docs should not contain:

- evolving PhD theory notes
- informal experiment interpretation
- algorithm-review narratives that are not user-facing documentation
- cross-stream research synthesis

Those belong in Obsidian, linked from the QuMET PhD project note.
